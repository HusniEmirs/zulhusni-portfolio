# Developer Portfolio

A personal software developer portfolio focused on engineering experience, technical capability, problem solving, and selected project work.

## Stack

- React
- TypeScript
- Vite
- ESLint
- CSS

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

## Status

The initial project foundation is in place. Portfolio content and the final visual design have not yet been implemented.
